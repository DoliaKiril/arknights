# Endfield Tactical Helper (Arknights: Endfield)

Автономный тактический помощник, конструктор отрядов по ДНК и Цепочкам Атак, калькулятор характеристик («До боя» и «В бою») и полная энциклопедия по боевой системе **Arknights: Endfield**.

## Состав проекта
- `index.html` — главное веб-приложение (7 вкладок, 3D-параллакс 60/120 FPS, Тёмная/Светлая темы, офлайн-кеш IndexedDB Vault).
- `db_characters.js` — полная база всех **34 актуальных играбельных оперативников** (19×6★, 10×5★, 5×4★) + математический движок `window.DNA_CHAIN_ENGINE`.
- `db_equipment.js` — полная база всех **18 комплектов боевой экипировки (3-PC)** и **53 видов оружия** всех 5 классов.
- `db_mechanics.js` — энциклопедия боевых механик и 4 эталонных шаблона промптов для ИИ.
- `ai_prompts/` — готовые `.txt` шаблоны промптов для генерации новых модулей.
- `package.json`, `capacitor.config.json`, `.github/workflows/build.yml` — конфигурация для автоматической облачной сборки Android `.apk` через GitHub Actions.

## Как собрать Android `.apk` за 2 минуты через GitHub
1. Создайте новый репозиторий на GitHub и загрузите в него содержимое этого архива (включая скрытую папку `.github/workflows/build.yml`).
2. Перейдите во вкладку **Actions** вашего репозитория и запустите воркфлоу **Build Endfield Tactical Helper Android APK**.
3. Скачайте готовый установочный файл `Endfield-Tactical-Helper-APK` (`app-debug.apk`) в блоке **Artifacts**.
